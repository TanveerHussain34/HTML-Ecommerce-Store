# HTML Ecommerce Store

A basic eCommerce store website built entirely using **HTML5**. The project demonstrates the fundamental structure of an online shopping website using static web pages, navigation links, and semantic HTML elements without relying on CSS frameworks or JavaScript.

## Overview

The HTML Ecommerce Store project focuses on the core structure of an eCommerce website. It provides a simple shopping experience through interconnected pages that showcase products and allow navigation between different sections of the site.

The project serves as a beginner-friendly example for understanding how multi-page websites are built using HTML and how web pages can be linked together to create a complete user journey.

---

## Project Structure

```text
HTML-Ecommerce-Store/
│
├── index.html          # Main storefront page
├── details.html        # Product details page
└── README.md           # Project documentation
```

> Note: The project is intentionally built using only HTML to demonstrate website structure, page navigation, and semantic markup fundamentals.

---

## Architecture

### Main Storefront (`index.html`)

The main page serves as the entry point of the application and contains:

* Product listings and previews
* Navigation links
* Storefront content sections
* Product information summaries
* Links to product detail pages

### Product Details (`details.html`)

The details page provides:

* Detailed product information
* Extended product descriptions
* Navigation back to the main storefront
* Structured content presentation using HTML elements

### Navigation Flow

The website follows a simple multi-page architecture:

```text
index.html
      │
      ▼
details.html
```

Users can navigate between pages through standard HTML anchor tags, demonstrating the foundational navigation mechanism used across websites.
